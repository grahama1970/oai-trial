# Test-family coverage report

Open [the HTML report](report.html), [Markdown](report.md), or the
[column-oriented family matrix](family-matrix.csv). [inventory.json](inventory.json)
contains every pytest case, its function, primary family, kind and observed result.

`report.json` is the authoritative `create_report.report.v1` model. It is validated
by `$create-report`; Markdown is generated by that skill. Pandoc renders semantic
HTML tables from the generated Markdown because the installed skill's HTML adapter
currently displays Markdown literally. No report conclusion is authored in HTML.

## Scope and interpretation

The inventory covers `security/tests`, not every test in the repository. Cases,
functions, parameter combinations and independent attack scenarios are different
units. Optional residual-risk cases are marked separately and do not authorize
release. Classification is a source-reviewed judgment recorded in
`security/test_catalog.json`, not a name-based heuristic.

The original WebGPT review judged its frozen pre-fix snapshot inadequate. Its four
supplied failing cases were reproduced, then corrected; the local no-progress
write case complements those checks. `remediation.json` links before/after evidence.
That is not a fresh reviewer PASS or a completed clean-container qualification.

## Regenerate from a fresh run (repository root)

1. Run `uv run pytest -q security/tests --junitxml=security/reports/adversarial-coverage/security-junit.xml`.
2. Record the run command, source commit, source-file SHA-256 values and JUnit
   SHA-256 in `test-run.json`; never rebind an old result to changed source.
3. Run `python scripts/report_test_coverage.py --junit security/reports/adversarial-coverage/security-junit.xml --run security/reports/adversarial-coverage/test-run.json --output security/reports/adversarial-coverage`.
4. Use the installed create-report skill to `validate report.json` and
   `render report.json --format markdown --output report.md`.
5. Run `pandoc --from=gfm --to=html5 --standalone --metadata pagetitle='Adversarial coverage' --css=report.css report.md --output report.html` from this directory.

Pass `--reviewer <Ask handler response.md>` and `--remediation <remediation.json>`
when preserving the baseline verdict and correction receipts. The report generator
requires an admitted, non-mocked Ask node receipt beside the reviewer response.

`fixtures/report_coverage_eval.json` retains source/result reconciliation and
refusal of tampered JUnit input; set `QUALIFICATION_ROOT` to a writable artifact
volume before running it with `$agentic-evals`.
